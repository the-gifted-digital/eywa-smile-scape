แนะนำ: Cabinet Grotesk (display) + DM Sans (body) + Noto Sans Thai (ไทย)

DM Sans เป็น geometric grotesque เหมือน Cabinet เลย → จับคู่กลมกลืน ดูพรีเมียม-คลีนตรงทิศ Bridge และ x-height ใกล้ Noto Sans Thai ทำให้ไทย-อังกฤษผสมเนียน. เลือก Rubik ถ้าอยากได้ "มน-อบอุ่น" มากกว่าความพรีเมียม

fontFamily: {
  display: "'Cabinet Grotesk', 'Noto Sans Thai', sans-serif", // hero / headings
  sans:   "'DM Sans', 'Noto Sans Thai', system-ui, sans-serif", // body / UI
  mono:   "ui-monospace, Menlo, monospace"
}
// Tailwind: font-display (หัว) · font-sans (เนื้อ) · ไทยทุกที่ fallback → Noto
เคาะ DM Sans หรือ Rubik → ผมจะเพิ่ม typography.fontFamily.display + sans ลง tokens.json, เดิน @fontsource (DM Sans / Rubik) + self-host Cabinet Grotesk จาก Fontshare, แล้ว build ให้ดูจริง · ยังไม่แตะ tokens
