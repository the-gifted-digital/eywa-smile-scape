## Primary Persona — ผู้ป่วยไทยวัยทำงาน-ก่อนเกษียณ

### Demographics

- **Age range:** 35-60
- **Gender:** Mix — implant skews female 55%, male 45% (bone loss cases); All-on-X skews slightly older + higher male proportion
- **Income tier:** มีรายได้ปานกลาง-สูง (upper-middle class) — ทำงานประจำ, เจ้าของธุรกิจ, freelance professional — สามารถจ่าย 30,000-150,000 THB ได้ แต่ต้องการความคุ้มค่า และ prefer ผ่อน 0% ถ้ามี
- **Location:** นนทบุรี (รัตนาธิเบศร์ + ใกล้เคียง) / กรุงเทพตะวันออก (ศรีนครินทร์ + สมุทรปราการ) / commute zone ใกล้ MRT สายสีม่วง + สายสีเหลือง
- **Occupation patterns:** พนักงานออฟฟิศระดับกลาง-สูง / เจ้าของกิจการ SME / ข้าราชการ / พยาบาล-บุคลากรทางการแพทย์ / แม่บ้านที่มีรายได้ครัวเรือนสูง

### Psychographics

- **Values:** สุขภาพระยะยาว / คุณภาพ-ความทนทาน / ความน่าเชื่อถือของหมอ / ไม่อยาก "ทำซ้ำ" — ต้องการ do it right ครั้งเดียว
- **Lifestyle:** ใช้ LINE เป็นหลักสำหรับ communication / ค้นหาข้อมูลจาก Google + YouTube + Facebook group / ถามคนรู้จักก่อนตัดสินใจใหญ่ / ดูรีวิว Google Maps / ไม่ค่อยใช้ TikTok (แต่ลูกหลานอาจแชร์มาให้ดู)
- **Health literacy:** ปานกลาง — ค้นหาข้อมูลเองได้แต่ไม่ลึกมาก / trust professional opinion สูง / กลัวโดน oversell
- **Brand sensitivity:** ให้ความสำคัญกับ "ชื่อเสียงหมอ" มากกว่าชื่อคลินิก / ชื่อ brand implant รู้จัก Straumann แต่ไม่รู้ความแตกต่างชัด / prefer หมอที่ "อธิบายดี ไม่กดดัน"

### Decision drivers

| Driver | Weight | Notes |
|--------|--------|-------|
| Doctor expertise + trust | High | "หมอมีประสบการณ์ไหม" — ดูวุฒิ, ดู before/after, ถามคนรู้จัก |
| Price / value clarity | High | ต้องการรู้ราคาชัดเจน — กลัว "ราคาเริ่มต้น" ที่บวกจนพุ่ง |
| Warranty / safety | High | รากฟันเทียมคือ investment ระยะยาว — warranty ตลอดชีพ vs 10 ปี มีผล |
| Clinic reputation | Medium-High | Review Google / Facebook / ปากต่อปาก — 4.8+ star สำคัญ |
| Technology / modernity | Medium | Digital planning + 3D X-ray บอก "มืออาชีพ" แต่ไม่ใช่ primary driver |
| Location convenience | Medium | MRT access + parking เป็น hygiene factor — ไม่ใช่ dealmaker แต่ทำให้ decide ง่ายขึ้น |
| Installment / financing | Medium | ผ่อน 0% ลดแรงกดดัน — สำคัญโดยเฉพาะ >50,000 THB cases |
| Peer recommendation | Medium-High | "เพื่อน/ญาติทำที่นี่แล้วดี" — นำมาสู่การนัด มากกว่า SERP |

## Secondary Personas

### Persona 2 — ผู้สูงอายุ (65+) และครอบครัวที่ดูแล

- **Profile:** อายุ 65-80 / ฟันหลุด-หลายซี่หรือทั้งปาก / บางคนใส่ฟันปลอมมา 10 ปีแล้วไม่สบาย / ลูกหลานเป็น decision influencer หลัก
- **Key concern:** "ผ่าตัดแล้วปลอดภัยไหม" / "อายุมากแล้วยังทำได้ไหม" / "ฟื้นตัวนานแค่ไหน"
- **Content need:** All-on-X / ฟันทั้งปาก educational pages + reassurance content for older patients + case studies
- **CTA pattern:** มักให้ลูกหลาน book แทน / "นัดปรึกษาฟรี ไม่มีค่าใช้จ่าย"
- **Funnel entry:** ลูกหลาน Google แทน หรือหมอ/พยาบาลแนะนำ

### Persona 3 — วัยรุ่น-วัยทำงานตอนต้น จัดฟัน (20-35)

- **Profile:** อายุ 20-35 / สนใจจัดฟันใส TrioClear หรือ Damon / คำนึงถึง aesthetics + ความสะดวก + ราคา
- **Key concern:** "จัดฟันใสผลดีเท่า แบบมีลวดไหม" / "กี่เดือน" / "ราคาเท่าไหร่ ผ่อนได้ไหม"
- **Content need:** Comparison (TrioClear vs Invisalign / บรักเก็ตกับจัดฟันใส) + before/after + timeline
- **CTA pattern:** "นัดตรวจฟันฟรี" / "ดูราคา" / "Add LINE"
- **Funnel entry:** Instagram / TikTok (ดูรีวิว) → Google → website

## Funnel Stage Map

### Awareness Stage

**Patient state:** "สังเกตว่าฟันตัวเองมีปัญหา หรือเริ่มอยากแก้ไข"

**Painpoints at this stage:**

1. ฟันหลุด 1 ซี่ขึ้นไป — เคี้ยวอาหารไม่สะดวก ไม่สบายใจ
2. ปวดฟัน / เสียวฟัน บ่อยขึ้น จนไม่กล้ากินของร้อน/เย็น
3. ยิ้มแล้วอายเพราะฟันไม่สวย / ฟันเว้า-เว้า / สีฟันเหลือง
4. ใส่ฟันปลอมแล้วไม่สบาย หลุดบ่อย กินอาหารไม่ได้
5. เห็นคนรู้จักทำรากฟันเทียมแล้วดูดี อยากรู้ว่าตัวเองทำได้ไหม

**Anxiety triggers:**

- ไม่รู้ว่า "ปัญหาฟันตัวเอง" รุนแรงแค่ไหน — ต้องรักษา หรือยังรอได้
- กลัวค่าใช้จ่ายสูงเกินงบ
- ไม่กล้าเข้าคลินิก เพราะไม่รู้ว่าจะถูกชวนซื้อของแพง

**Information they seek:**

- "รากฟันเทียมคืออะไร" / "ฟันหลุดต้องทำอะไร"
- "ฟันหลุดทิ้งไว้นานมีผลไหม"
- "รากฟันเทียมกับฟันปลอม ต่างกันยังไง"
- "เมื่อไหร่ควรไปพบทันตแพทย์"

**Content type fit:** T1 Condition pages (ฟันหลุด, กระดูกละลาย), T6a Guide (คู่มือผู้ป่วย), FAQ (T6b)

**CTA pattern:** "อ่านต่อ" / "ปรึกษาฟรี ไม่มีค่าใช้จ่าย" / "เช็กสัญญาณ 5 อย่างที่ต้องไปหาหมอ"

### Consideration Stage

**Patient state:** "กำลังศึกษาตัวเลือก — รากฟันเทียม? ฟันปลอม? คลินิกไหน? หมอคนไหน?"

**Painpoints at this stage:**

1. สับสนระหว่าง brand รากฟันเทียม (Straumann vs Neodent vs Blue Diamond — ต่างกันยังไง?)
2. กลัวเจ็บ / กังวลเรื่องการผ่าตัด
3. ไม่รู้ราคาจริง — "ราคาเริ่มต้น" กับ "ราคาจริงที่จ่าย" ต่างกันเยอะไหม
4. ไม่รู้วิธีเลือกหมอ — ดูอะไร? ถามอะไร?
5. กังวลว่ากระดูกไม่พอ — "ทำได้ไหม ถ้ากระดูกน้อย"

**Anxiety triggers:**

- ตัดสินใจผิด → ต้องแก้ทีหลัง = เสียเงิน+เวลา+ความเจ็บปวดซ้ำ
- หมอกดดันให้ซื้อ package แพง
- เลือก brand ที่ไม่ดี → รากฟันเทียมอายุสั้น

**Information they seek:**

- Comparison: รากฟันเทียม brand A vs B
- Case studies / before-after (เคสใกล้เคียงกับตัวเอง)
- "ทำรากฟันเทียม เจ็บไหม" / "กี่วันฟื้น"
- "กระดูกน้อยทำรากฟันเทียมได้ไหม"
- "Sausage Technique คืออะไร" (สำหรับ high-awareness patients)
- รีวิวจากคนไข้จริง

**Content type fit:** T2 Service pages (implant deep-dive), T17 Case studies, T6b Comparison/FAQ, T9 Doctor profile

**CTA pattern:** "ดูเคสจริง" / "พบหมอแฮม" / "ขอ quote รักษา" / "ดูข้อแตกต่าง"

---

### Decision Stage

**Patient state:** "ตัดสินใจแล้วว่าจะทำ — กำลังเลือกคลินิกสุดท้าย"

**Painpoints at this stage:**

1. ไม่แน่ใจเรื่องความปลอดภัย — "คลินิกนี้ได้มาตรฐานไหม"
2. Payment options ไม่ชัด — "ผ่อน 0% ได้จริงไหม? เงื่อนไขยุ่งยากไหม"
3. Scheduling friction — "นัดยาก เดินทางไม่สะดวก"
4. ยังไม่แน่ใจว่า "คุ้มไหม" ถ้าเทียบกับคลินิกที่ถูกกว่า

**Anxiety triggers:**

- นัดแรก — ไม่รู้ว่าจะเจออะไร เดินเข้าไปแล้วจะถูกบังคับซื้อไหม
- Financial commitment ก้อนใหญ่

**Information they seek:**

- Branch location + parking + ชั่วโมงเปิด-ปิด
- Payment / installment details (ผ่อน 0% กี่เดือน? ใช้บัตรอะไรได้บ้าง?)
- Pre-visit: ต้องเตรียมตัวอะไรบ้าง / X-ray ต้องทำเองไหม
- "นัดแรกทำอะไรบ้าง" — demystify first visit

**Content type fit:** T7 Branch page, T2 commercial section (pricing/installment), T11 Patient guide, CTA landing

**CTA pattern:** "จองคิวออนไลน์" / "Add LINE @SmileScape" / "โทรนัด" / "สมัคร 0% บัตรเครดิต"

---

### Post-Visit / Loyalty Stage

**Patient state:** "ทำเสร็จแล้ว — อยากรู้วิธีดูแลรักษา + อยากแนะนำคนอื่น"

**Painpoints at this stage:**

1. จำคำแนะนำหมอไม่ได้ทั้งหมด — "หลังทำรากฟันเทียมแปรงฟันยังไง"
2. ไม่แน่ใจว่าควรมา follow-up เมื่อไหร่
3. อยากแนะนำพ่อแม่/เพื่อน แต่ไม่รู้จะพูดยังไง

**Content type fit:** T6a Aftercare guide (post-implant care), follow-up reminders (LINE OA), referral mechanics

**CTA pattern:** "ดาวน์โหลดคู่มือดูแลรากฟันเทียม" / "นัด follow-up 6 เดือน" / "แนะนำเพื่อน รับส่วนลด"

## Voice Calibration Cheat Sheet (for Phase F content writers)

```yaml
high_anxiety_content:
  open_with: "เราเข้าใจว่าการผ่าตัดช่องปากอาจทำให้กังวล..."
  avoid: รายละเอียดทางคลินิกที่ graphic โดยไม่มี warning / jargon ที่ไม่อธิบาย
  emphasize: safety record / credentials หมอแฮม / testimonials จริง / ผ่าน X,XXX เคส
  CTA: low-friction ("ปรึกษาหมอฟรี ไม่มีค่าใช้จ่าย ไม่ต้องตัดสินใจ")
  tone: warm + professional + slow + step-by-step

medium_anxiety_content:
  open_with: framing ที่ชัดเจนว่าบทความนี้จะตอบอะไร
  avoid: over-promising ("รับประกัน 100%") / reassurance ที่ลอย ๆ ไม่มีหลักฐาน
  emphasize: process clarity / expected timeline / อธิบายด้วย evidence + ประสบการณ์หมอ
  CTA: medium-friction ("ดูเคสจริง" / "ขอ quote รักษา")
  tone: factual + confident + evidence-based

low_anxiety_content:
  open_with: direct answer (TL;DR style)
  avoid: unnecessary hedging / burying the answer in 3 paragraphs
  emphasize: depth + technical accuracy + comparison table
  CTA: any (no anxiety friction)
  tone: informational + neutral + precise
```

## SmileScape-Specific Brand Voice Notes

**"Family Standard" principle** (จาก brand-config.json):
> "ถ้าเคสนี้เราไม่กล้าทำให้พ่อแม่ตัวเอง เราจะไม่ทำคนไข้เด็ดขาด"

Use this principle in:
- High-anxiety content (reassurance anchor)
- Case study intros (explain selection criteria)
- Doctor profile page (personal philosophy)
- Pricing/installment pages (transparency framing)

**SMILE DNA เข้าสู่ content:**
- **S — Sincere Care:** anti-oversell framing, transparency in pricing
- **M — Mastery:** cite Urban/ILAPEO/Kern credentials explicitly when relevant
- **I — Integrity:** acknowledge what we can't do / refer out honestly (builds trust)
- **L — Lifelong Learning:** position new techniques (Sausage, Ceramic) as ongoing commitment
- **E — Efficiency:** Digital 100% workflow → faster planning, fewer surprises
